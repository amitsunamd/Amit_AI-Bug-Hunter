# Amit_AI-Bug-Hunter

Mobile-first website quality and security-header checker, with an Android APK build workflow.

## Features
- HTTP response status and common security-header checks
- Basic HTML title, meta description and image-alt checks
- Heuristic password-form and mixed-content checks
- Small sample of same-host links
- JSON report export
- Backend URL can be configured in the dashboard and saved on the device
- Android debug APK generated by GitHub Actions
- Python safety tests on every push

## Important safety boundaries
Only test websites you own or have explicit permission to assess. The scanner blocks local/private IP targets, non-HTTP(S) schemes, custom ports and cross-host redirects. It does not exploit vulnerabilities, brute-force accounts, bypass logins or run destructive tests. Automated results are heuristics, not proof of a vulnerability; verify manually. It is not a substitute for a professional penetration test.

## Backend
From `backend/`:
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
Health endpoint: `/health`; interactive API docs: `/docs`.

## Deploy backend
The repository includes `render.yaml` for a Render Blueprint. Sign in to Render, create a new Blueprint deployment from this repository, review the service settings, and deploy. Once Render provides the service URL, enter it in the dashboard's **Backend API URL** field and tap **Save**. The backend is not publicly hosted automatically by GitHub; a hosting account and deployment approval are required.

Before production, replace wildcard CORS in `backend/main.py` with the exact dashboard origin and review hosting/network restrictions.

## Dashboard deployment
The GitHub Pages workflow is configured to deploy the `frontend/` directory. The repository owner must enable GitHub Pages in repository Settings → Pages and set the build/deployment source to **GitHub Actions**. The linked GitHub App token currently cannot create the Pages site itself. After enabling Pages, rerun the Pages workflow under Actions.

## Android APK
GitHub Actions builds a debug APK on pushes and manual workflow dispatches. Open the repository's Actions tab, select **Build AI Bug Hunter Android APK**, open a successful run, and download the `ai-bug-hunter-debug-apk` artifact. This is a debug APK for testing, not a Play Store-signed release. Configure the backend URL in the app after installing it.

## Tests
GitHub Actions runs backend safety tests with pytest.
